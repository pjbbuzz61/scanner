Notes for 2026 collection of bets

All 8 sites will give the time of the contest. 
All but BetMGM give the time the bet was made, 365, betrivvers and DK dont give the conclusion time
So using the event start time as the ref is the only choice

Unfortunately it looks like I'll have to scrape DK from html. I can't see how the data gets back to the client.
Bet365 also has the goofy format for data, so that might have to be scraped also.

Acquiring data
BetMGM:
 log in, go to MyBets on top far right, go to Settled, select the data range. The json comes back as json in 
 betslips calls, each return needs to go into its own file. Urls start with 'betslips'
 NOTE: setting maxItems limits you to 50 on a return, but you can one up the index to get the next batch of 50!
 
 
Caesars
 login, select Settled from the right hand side slip, as you scroll down it'll make calls to get data. Doesn't look 
 to be a way to set a date range, but you can see what dates are used from the url. Urls start with 'history'
 Note: Site not happy at all when the page size is messed with!!!
 
 
FanDuel
 login, go to My Bets, go to Settled Bets. json comes back with 'fetch-my-bets' urls. Each state will have to be
 pulled separately, so add the state in lower case to the file name (with an underscore at the start)
 NOTE: you can set the to and from record fields with an up to 100 diff. So set first time to 1 to 100, 
       the next 101 to 200, etc

ESPN: (589)
 login, go to MyBets on the left, go to Settled and select all. The urls seem to start with something random
 each time so it has to be figured out. I ended up using Chrome to capture back from 2/14 to jan 1 because all 
 the responses after about 30 days were getting truncated in FF. Worked in chrome, but I used the RemoveRtns class 
 to take out all the spaces since it had it in the expanded format (not on one line)
 
 
DraftKings:
 Unfortunately have to go with html. Go to My Bets, select Settled. The tag to look for is sb-lazy-render. Looks
 like 25 are displayed by default. When you scroll down you'll see the lazy-render lose its data and a new one will show up
 NOTE!!!! - you have to expand out the parlays before you capture the hthml, otherwise you don't get the starting times
 for the games!!
 
BetRivers
 login, mybets, settled. Comes back with url starting with coupons
 NOTE: Change the range size to 1000 and you'll get everything!! 
       And the Collector will filter out the ones not on our year.
       
       
Bet365:
 Go to pic on top right, select history. Select Settled Bets, and the date range you want. You have to hit 
 the bet details for each entry, which will generate a text blob with a url starting in confirmation.
 
Hard Rock:
 Comes out as betHistory. Have to use PB -> History -> Bet History, then select the range for the pull.
